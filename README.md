# FitTrack — Expo React Native App

A mobile fitness tracker built with Expo SDK 52, expo-router, and expo-sqlite. The app works fully offline, with all data stored locally on the device. No backend, authentication, or cloud services are used.

## Features

- Native iOS and Android support using Expo
- Local data persistence using SQLite (expo-sqlite)
- Three main screens: Dashboard, Log, and Charts
- Dark and light mode toggle with persistence via AsyncStorage
- Neo-brutalist UI design with custom fonts (Bebas Neue, Space Mono)
- Full CRUD functionality (add, edit, delete records)
- Slide-up modal for record entry
- SVG-based charts:
  - Bar charts for calories and steps
  - Line chart for weight trends
- Fully offline functionality
